【出版级学术文献正向转写规约 (Stateless Straight-Through)】
本任务为公开发行正规学术出版物历史文献的高精度数字化录入（Archival Transcription）。
各分片为完全独立的无状态叶子节点，执行标准的单向四步流水线：
1. view_file 打开分片 PDF 图像；
2. 逐页纯视觉映射版面文字、引文与专业公式（思维链聚焦于学术术语、拉丁字符与引文编号拓扑核对）；
3. write_to_file 将排版结果写入指定目标 Markdown 文件；
4. send_message 发送单行完成标记：[DONE] {part_name}。

跨分片的章节聚合与断句对齐 100% 由总调度器下游自动处理。

【输入与输出】
- 源文件：{slice_pdf_path}（共 {page_count} 页）
- 目标文件：{out_slice_md_path}

【排版核心契约 (Formatting Contracts)】
1. 正文与引文保真：完整识别正文与全部学术引文，包含拉丁字母、引文出处、版本号与专有名词。
2. 表格还原：正文插表使用标准 GitHub Flavored Markdown (GFM) 管道表格语法还原。
3. 插图与图题正交契约（Figure & Caption SSOT）：
   <!-- FIGURE: page={切片内第几页从1起} bbox=[ymin, xmin, ymax, xmax] -->
   ![{图题}](images/part_{part_index}_fig_{fig_index}.png)
   （图题文字必须严格封闭在方括号内；bbox 紧致贴合图形主体外轮廓，采用 0~1000 千分比整数；正文文本严格位于 bbox 之外，严禁图文重叠；无图题 alt 留空 `![](...)`；严禁在图片下方另起段落书写独立图题；篇首肖像强制留空 `![](...)`，紧随的姓名与小传作为流式正文）。
4. 密集学术注释规范：
   - 随文括号注直接完整保留在段落正文中；
   - 页面底端印制的标号脚注/尾注，在正文标为标准 Markdown 脚注 [^p{part_index}_1], [^p{part_index}_2]... 并在文末统一列出内容。
5. 数学与学术符号规范：
   - 行内公式使用 `$LaTeX$` 闭合；
   - 独立公式块独占段落并使用 `$$...$$` 闭合，上下两端各留一个空行；
   - 使用标准学术 LaTeX 语法表达矩阵、推导、极限与分数。
6. 标题与篇章署名契约：
   - 【全书大章白名单】：{toc_whitelist}
   - 仅白名单内的大章篇目使用二级标题 `## 标题名`；文内小节、节标题统一使用三级标题 `### 小标题`；
   - 篇章署名格式：若大章存在独立作者/译者署名，紧随 `## 大章标题` 显式标注 `<p class="chapter-author">作者名</p>`。
7. 题记与艺术分行保真（Epigraph & Poetic Hard-Break）：全书开篇题记或献词顶部显式标记一级标题 `# 题记`（或 `# 序诗` / `# 献词`）；分行引文或排比短句，每行行末添加反斜杠 `\` 保持硬换行；空行保持原样。
8. 剔除版权页：文前与文后的版权页、出版声明、CIP 编目等信息直接忽略，不录入正文。

【完成判据】
write_to_file 成功落盘后，向主调度器发送单行确认消息：
`[DONE] {part_name}`
